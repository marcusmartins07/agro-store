# Skill: TCC

## Objetivo

Orientar o desenvolvimento e a documentação do Agro Store considerando que o projeto é um MVP para Trabalho de Conclusão de Curso.

## Escopo

O Agro Store é uma plataforma digital para comercialização de produtos rurais, voltada ao contexto da Feira do Produtor Rural Willi Dummer, em Camaquã/RS.

O objetivo é entregar um sistema funcional, demonstrando:

- Levantamento de requisitos.
- Modelagem.
- Desenvolvimento backend.
- Desenvolvimento frontend.
- Integração via API REST.
- Autenticação.
- Fluxo de compra.
- Carrinho.
- Pedidos separados por produtor.
- Retirada presencial na feira.

## Regras

- Priorizar funcionalidades essenciais para apresentação.
- Evitar complexidade que não ajude no TCC.
- Não implementar pagamento online.
- Não implementar entrega.
- Não implementar funcionalidades fora do MVP sem necessidade.
- Manter coerência entre texto do TCC, diagramas e sistema implementado.
- Quando uma regra mudar no código, avaliar se o texto do TCC precisa ser atualizado.

## Funcionalidades centrais para o TCC

- Login e autenticação.
- Cadastro de usuário.
- Perfil de cliente.
- Perfil de produtor/agricultor.
- Cadastro de loja/produtor.
- Cadastro de produtos pelo produtor.
- Listagem de produtos.
- Favoritos.
- Carrinho.
- Finalização do pedido.
- Separação de pedidos por produtor.
- Histórico de pedidos.
- Atualização de status pelo produtor.
- Avaliações de produtos comprados.

## Linguagem acadêmica

Ao gerar texto para o TCC:

- Usar linguagem formal.
- Evitar termos excessivamente técnicos sem explicação.
- Explicar decisões de arquitetura.
- Relacionar funcionalidades com objetivos do sistema.
- Não afirmar que algo foi implementado se ainda não foi.
- Diferenciar funcionalidades implementadas de trabalhos futuros.

## Pontos que podem virar trabalhos futuros

- Pagamento online.
- Entrega em domicílio.
- Notificações.
- Aplicativo mobile.
- Relatórios avançados.
- Integração com meios de pagamento.
- Chat entre cliente e produtor.
- Controle avançado de estoque.
