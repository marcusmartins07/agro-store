# Skill: Documentação

## Objetivo

Manter documentação técnica e acadêmica do Agro Store.

## Regras obrigatórias

- Atualizar documentação quando houver alteração relevante.
- Escrever de forma clara e objetiva.
- Evitar linguagem excessivamente informal na documentação acadêmica.
- Diferenciar documentação técnica de texto para TCC.
- Manter coerência com o que foi realmente implementado.
- Não afirmar que uma funcionalidade existe se ainda não foi implementada.

## Documentação técnica

Pode incluir:

- Como rodar o projeto.
- Estrutura do monorepo.
- Variáveis de ambiente.
- Endpoints principais.
- Regras de negócio.
- Fluxos implementados.
- Comandos úteis.
- Organização do backend.
- Organização do frontend.

## Documentação acadêmica

Deve explicar:

- Objetivo do sistema.
- Tecnologias utilizadas.
- Arquitetura.
- Modelagem.
- Fluxos principais.
- Justificativas técnicas.
- Limitações do MVP.
- Trabalhos futuros.

## Regras para README

O README deve conter no mínimo:

- Nome do projeto.
- Descrição.
- Tecnologias.
- Estrutura.
- Como instalar.
- Como executar.
- Comandos úteis.
- Variáveis de ambiente.
- Funcionalidades principais.

## Regras para documentação de API

Sempre que endpoint relevante for criado ou alterado, documentar:

- Método HTTP.
- URL.
- Autenticação necessária.
- Payload esperado.
- Resposta esperada.
- Possíveis erros.
